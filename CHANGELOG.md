# Changelog

All notable changes to this project are documented here. Format based on [Keep a Changelog](https://keepachangelog.com/), versions follow [Semantic Versioning](https://semver.org/).

## [Unreleased]

## [2.3] - 2026-10-22

### Changed
- Instagram: a profile's stories and highlights can be watched from that profile. The stories tray in the home feed stays hidden.

## [2.2] - 2026-10-19

First public release on Firefox Add-ons.

### Added
- Open source project: MIT license, contribution guide, privacy policy, tests and GitHub workflows.

## [2.1] - 2026-10-18

### Added
- **Profiles**: each one with its own schedule, sites and Shorts option. Several can be active at once and the strictest rule wins for each site.
- "Now" tab showing active profiles and the rules applied to each site.
- Profile templates: Social media, Work hours and Blank.
- "All day" option in schedules.

### Changed
- The panel has a fixed height, so it no longer flickers when switching tabs.
- Strict mode locks every profile while any of them is active.
- Existing settings are migrated to a "Principal" profile.

## [2.0] - 2026-10-18

### Added
- Hide feeds instead of blocking the whole site on X, Instagram (including stories), YouTube, Facebook and Reddit.
- Daily time limit per site, with a 5-minute warning and a block screen at the limit.
- Progressive unlock wait: each unlock of the day doubles the wait.
- Redesigned panel with light and dark themes.

## [1.3] - 2026-10-18

### Added
- New name (Ancla) and icon.
- Intro message when the settings are locked.

## [1.2] - 2026-10-18

### Added
- Strict mode with a waiting tab to unlock the settings.

## [1.1] - 2026-10-18

### Added
- Blocking schedule by days and hours.

## [1.0] - 2026-10-18

### Added
- Hide YouTube Shorts, block sites and grayscale sites.
